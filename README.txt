Luv Sync (прототип 0.1.0) — мини-приложение для Amazfit Bip Max, которое обновляет цвета полосок на циферблате Luv Face.

КАК ЭТО РАБОТАЕТ
Циферблат сам получать данные не может. Поэтому: циферблат при включении экрана запускает Luv Sync; Luv Sync кладёт цвета шести сегментов
в общую память часов (hmFS.SysProSetChars, ключ luv_c) и возвращает на циферблат; циферблат читает их и красит полоски.
ПРОТОТИП: цвета пока придуманные (shared/testdata.js), с каждой записью другие — чтобы было видно, что обновление дошло.
Настоящие цвета (те же, что у виджета статистики) будет присылать телефон — это следующий шаг, здесь его ещё нет.
Приложения «Таймер» и LuvU613 (телефон) этот проект не трогает.

КАК УСТАНОВИТЬ (так же, как циферблат)
1. Создайте НОВЫЙ репозиторий на GitHub (отдельный, не тот, где циферблат) и загрузите в него ВСЁ из этой папки.
   Файл сборки: Add file -> Create new file, имя .github/workflows/build.yml, внутрь текст из файла build.yml.
2. Settings -> Pages: публикация из ветки gh-pages. Вкладка Actions: дождаться зелёной галочки
   (если первый запуск прошёл до включения Pages — Actions -> Run workflow ещё раз).
3. QR-код "square-432x514" -> в Zepp: Профиль -> часы -> Режим разработчика -> сканировать.
4. Приложение появится в списке приложений часов под названием Luv Sync.

ПРОВЕРКА
Откройте Luv Sync вручную из списка приложений: шесть цветных квадратов и «Готово. Запись № N (hmFS)» — значит, запись в общую память работает.
Открытое вручную, оно никуда не возвращает. Если вместо этого красная «ОШИБКА: ...» — пришлите её текст.
Запущенное циферблатом, оно само возвращает на циферблат через 1,2 секунды (при ошибке — через 10, чтобы успеть прочитать).

ГДЕ ЧТО МЕНЯТЬ
page/index.js   — OK_BACK_MS / ERR_BACK_MS (через сколько возвращает на циферблат), порядок способов возврата (goHome).
shared/link.js  — ключи общей памяти и формат записи (такой же файл в проекте Luv Face; менять только в обоих сразу).

ТЕСТЫ (необязательно): npm test.
